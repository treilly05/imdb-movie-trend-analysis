# IMDb Movie Trend Analysis

## Project Overview
This project explores historical movie and television trends using IMDb data, SQL queries, pandas, and data visualization techniques. The notebook analyzes movie ratings, genre popularity, and audience engagement across different time periods to better understand how entertainment trends and public interests have evolved over time.

## What the Notebook Does
The notebook connects to an IMDb SQLite database and analyzes movie and television data across multiple historical periods. SQL joins are used to combine title, ratings, and genre information before importing the results into pandas DataFrames for analysis.

The project examines audience engagement by identifying the most-voted titles during specific years, including the 2007–2009 recession period. It also analyzes genre popularity trends over time and compares rating distributions across genres using visualizations such as bar charts, line graphs, and boxplots.

The notebook demonstrates how SQL and Python can work together to explore large relational datasets and generate meaningful insights from entertainment data.
